# Licensing notes

*Not legal advice. This is a working summary of the providers' published terms as read on 2026-10-13.*

The repository holds two kinds of material:

1. **Code and docs** (`game/`, `data/pipeline/`, `docs/`) written for this project. The owner can license them freely.
2. **Derived data** (`data/out/*.json`): extracts, aggregates and model parameters computed from third-party statistics. Each source keeps its own terms, and a code licence does not cover them. The game reads these files at runtime (`game/vite.config` serves `../data/out` as the public directory).

"Verified" means the licence was read on a page or file published by the provider itself. "Partly" means the provider's own material was read but it does not state the terms for this exact dataset. "Unverified" means no provider statement was found; what was tried is listed.

## 3. Recommended setup

1. **Code and docs: MIT** (`LICENSE` at the root). Apache-2.0 also works if a patent grant is wanted. State in `LICENSE` that it does not cover `data/out/`.
2. **Derived data in `data/out/`: CC BY-SA 4.0** (`data/out/LICENSE`), covering the project's own selection and computation. CC BY 4.0 and CC BY 3.0 IGO inputs can be adapted under CC BY-SA, and the Wikipedia and UIS inputs require it. Note in the licence file that third-party terms listed in `ATTRIBUTION.md` continue to apply to the underlying figures (WHO additional terms, IMF commercial permission, UNHCR and OECD attribution rules).
3. **`returns.json`:** done — replaced by the summary-statistics model `returns_model.json`; the yearly rows are not published.
4. **Before any commercial release** (paid game, ads, app store): replace or get permission for IMF `gdp_ppp`, resolve the UIS NC label, and check WHO and NCD-RisC.
5. **`ATTRIBUTION.md`** at the root (contents in section 4), linked from `README.md` and from an "About the data" screen in the game. `NOTICE` (if Apache-2.0 is chosen) should just say: "This product includes data from third parties; see ATTRIBUTION.md. Derived data in data/out/ is licensed under CC BY-SA 4.0 except where stated."
6. Do not use any provider's logo or imply endorsement (UN, WHO, World Bank, UIS, UNHCR, OECD, ILO all say so).
